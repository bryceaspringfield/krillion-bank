# Krillion question bank

Every prompt dealt in [Krillion](https://playdaily.org/krillion) (playdaily.org) that this bank has collected, with every answer known to score on each, by tier: the answers the game lists after a round, answers checked against the game, and other players' answers in multiplayer rounds.

The page: https://bryceaspringfield.github.io/krillion-bank/

Search a prompt in any of its wordings (multiplayer rewords prompts, e.g., "Name any one Ford model" for "Name a Ford model"), or an answer. Tier colors are the game's own.
